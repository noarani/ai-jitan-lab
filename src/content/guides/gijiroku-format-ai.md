議事録の担当になったとき、最初に迷うのは文章の書き方より「何を書くか」です。項目が決まっていないと、会議の流れを順番に書き写すだけになり、読む人が決定事項を探すことになります。

この記事では、議事録に入れる項目を、コピーして使える空のフォーマットにしました。そのフォーマットをAIに渡し、メモや文字起こしから埋めさせるプロンプトも載せています。例はすべて架空です。

## 議事録には、どんな項目を入れますか？

**結論：日時、参加者、目的、決定事項、宿題（誰が・いつまで）、保留事項、次回の7つがあれば、会議に出ていない人にも通じます。**

まず、空のフォーマットです。そのままコピーして、自分の会議に合わせて項目を足し引きしてください。

```text
# 議事録

## 会議情報
- 会議名：
- 日時：    年  月  日（  ）  :  ～  :
- 場所／形式：
- 参加者：
- 欠席者：
- 記録者：

## 目的
（この会議で何を決める・共有するのか。1〜2行）

## 決定事項
1.
2.

## 宿題（アクション項目）
| 内容 | 担当 | 期限 |
| --- | --- | --- |
|  |  |  |

## 保留事項（決まらなかったこと）
- 論点：
  状態：
  次に確認する人・場：

## 共有事項（決定ではない報告）
-

## 次回
- 日時：
- 議題の予定：
```

各項目に何を書くかは、次の表で確認できます。

| 項目 | 書くこと | 書き方の例（架空） |
| --- | --- | --- |
| 日時・参加者 | 開催日、時間、出席者と欠席者 | 10/20 14:00〜14:45／出席：佐藤、鈴木、田中／欠席：高橋 |
| 目的 | その会議で何をするのか | 来月のキャンペーン案を1つに絞る |
| 決定事項 | 合意されたことだけ | 案Bで進める |
| 宿題 | 内容、担当、期限の3点セット | 見積の再作成｜鈴木｜10/25 |
| 保留事項 | 決まらなかった論点と、次にどこで決めるか | 予算の上限。次回の定例で確認 |
| 共有事項 | 決定ではない報告や連絡 | 他部署の導入が来月になる見込み |
| 次回 | 日時と、予定している議題 | 11/3 14:00／効果測定の報告 |

「共有事項」は、決定事項と混ざりやすいので別欄にしました。「共有された」ことと「決まった」ことは違います。ここを分けておくと、あとで「あれは決まっていたはず」という行き違いが減ります。

## AIにフォーマットを渡して、どう埋めさせますか？

**結論：フォーマットを丸ごと渡し、目的と読み手を添えて、推測で埋めず、不明な欄は「未確認」と書くよう指示します。**

「議事録にして」とだけ頼むと、AIは自分の好みの構成で書き、メモにない担当者や期限まで自然な文章で補うことがあります。そこで、上のフォーマットをそのまま渡し、埋めるだけに役割を絞ります。

`[ ]` の中は自分の会議の内容に置き換えてください。

```text
次の会議メモをもとに、下のフォーマットを埋めて議事録の下書きを作成してください。

【この議事録の目的】
[例：会議に出られなかった部長が、決まったことと自分に必要な対応だけを3分で把握する]

【読み手】
[例：部内のメンバーと、出席できなかった部長]

【守ること】
- メモに書かれていない内容は補わない。推測で埋めない。
- 日付、金額、件数、人名、会社名は、メモにある表記のまま使う。計算や言い換えをしない。
- 「決定事項」には、メモから合意されたと分かることだけを入れる。案として出ただけのものは「保留事項」に入れる。
- 宿題は「内容・担当・期限」の3点がそろっているものだけをそのまま書く。1つでも不明なら、不明な項目を「未確認」と書く。
- 発言者が分からない箇所は、特定の人の発言にしない。
- 埋められない欄は消さず、「未確認」と書く。
- 最後に、「未確認」にした箇所を一覧で出す。

【フォーマット】
[上の空のフォーマットを貼る]

【会議メモ】
[ここに貼る]
```

最後の「未確認の一覧」は地味ですが効きます。AIが「ここは埋められなかった」と自分で申告するので、人が確認する場所が先に絞れます。

メモの段階で「確認済みの数字」と「うろ覚えの数字」を混ぜないことも大切です。うろ覚えの数字を確認済みと同じ書き方で渡すと、AIはそのまま文章に取り込みます。

入力前の情報の扱いについて、個人情報保護委員会は、生成AIサービスに個人情報を入力する場合に、入力された情報が機械学習に利用されることがあり、不正確な内容で出力されるリスクもあるため、そのリスクを踏まえて適切に判断するよう求めています。取引先名や個人名を含むメモは、置き換えるか、入力しないでください。 [個人情報保護委員会：生成AIサービスの利用に関する注意喚起等（PDF）](https://www.ppc.go.jp/files/pdf/230602_alert_generative_AI_service.pdf)

決定事項・継続検討・アクション項目の分け方を別の形式で見たい場合は、[AI議事録作成プロンプト](/ai-jitan-lab/ai-gijiroku/ai-gijiroku-sakusei-prompt/)も使えます。

## 会議の種類で、フォーマットはどう変えますか？

**結論：定例は「前回との差分」、商談は「相手の要望と持ち帰り」、1on1は「次までにやること」を厚くし、使わない欄は削ります。**

同じフォーマットを全部の会議に使うと、欄が空のまま残ります。種類ごとに、足すものと減らすものを決めておくと、AIへの指示も短くなります。

定例会議は、進捗の報告が中心です。「前回からの変更」「止まっていること」の欄を足し、決定事項は少なくても構いません。プロンプトには「進捗の報告と、検討中の話を同じ欄に入れない」と一文加えます。

商談や打ち合わせは、「相手の要望」「こちらの回答」「持ち帰り事項」を分けます。社外に約束したことと、社内で検討するだけのことが混ざると、あとで困ります。共有前に、社外へ出す内容かどうかを人が見ます。

1on1は、議事録というよりメモです。参加者は2人なので「参加者」欄は不要で、「話したこと」「次の1on1までにやること」「次回話すこと」の3欄で足ります。評価や家庭の事情など、個人に関わる内容が入りやすいので、AIに渡すかどうか自体を先に考えます。保存先と見られる範囲も、会議の前に決めておきます。

宿題の拾い方は、[ChatGPTで議事録を要約するプロンプト](/ai-jitan-lab/ai-gijiroku/ai-gijiroku-youyaku-prompt/)に詳しく書いています。

## AIが埋めた後に、人は何を確認しますか？

**結論：決定事項と宿題の担当・期限、数字、固有名詞、発言者の4点を、メモや録音に戻って確認します。**

AIの出力は、整っていて読みやすいぶん、間違いにも気づきにくくなります。次の順で見ます。

1. 決定事項：メモに「決定」「合意」の根拠があるか。会議中に出ただけの案が、決まったことになっていないか
2. 宿題の担当・期限：本人が引き受けた発言があるか。期限は会議で出た日付か。AIが「今週中」と補っていないか
3. 数字：金額、件数、日付を、メモや資料の元の数字と1つずつ照らす。桁や単位が変わっていないか
4. 固有名詞と発言者：会社名、製品名、人名の表記。誰の発言かが入れ替わっていないか

「しない」「見送る」のような否定は、抜けると結論が反対になります。決定事項の欄に否定の語が入る場合は、とくに元に戻って見てください。

文字起こしからフォーマットを埋めた場合は、そもそもの聞き間違いも混ざります。確認の順番は、[AI議事録の文字起こしを確認する方法](/ai-jitan-lab/ai-gijiroku/ai-gijiroku-mojiokoshi-kakunin/)にまとめています。

確認がすんだら、「未確認」の欄は、確認できた分だけ書き換えます。確認できなかった欄は、消さずに「未確認」のまま共有して、確認を頼む相手を添えてください。

## 議事録のフォーマットでよくある失敗は？

**結論：決定事項に案が混ざる、宿題の担当者や期限が空く、AIにフォーマットなしで任せる、文章を整えすぎて時間が足りなくなる、の4つです。**

決定事項に案が混ざる失敗は、メモを時系列で書いた場合に起きやすくなります。「Bで行こうか」と誰かが言っただけの場面が、「Bで進める」に化けます。フォーマットの「保留事項」欄を作っておくのは、案の置き場所をわざと用意するためです。

宿題の担当者が空く失敗もあります。会議では「誰かやっておいて」で終わることがあり、そのままAIに渡すと、AIが参加者の中から担当者を選んで書いてしまうことがあります。選んだのはAIで、会議で決まったことではありません。「担当：未確認」のまま共有して、会議後に決めてもらうほうが安全です。

フォーマットなしで「議事録を書いて」と頼むと、毎回見出しが変わります。読む人が探す場所を覚えられないので、使われなくなります。1度作ったフォーマットは、チームで同じものを使い続けてください。

4つ目は、議事録を完璧な文章にしようとして、時間が足りなくなる失敗もあります。議事録の役目は、決まったことと次の作業を伝えることです。発言をきれいにまとめる作業は、後回しで構いません。

## まとめ：フォーマットを先に決め、空欄は「未確認」で残す

議事録の項目は、日時、参加者、目的、決定事項、宿題、保留事項、次回の7つが基本です。この空のフォーマットをAIに渡し、メモにないことは補わず、不明な欄は「未確認」と書かせると、人が確認する場所が先に見えます。

会議の種類によって、足す欄と減らす欄は変えてください。AIが埋めたあとは、決定事項と宿題の担当・期限、数字、固有名詞、発言者を、メモに戻って確認します。共有する議事録の責任は、書いた人と共有した人にあります。
