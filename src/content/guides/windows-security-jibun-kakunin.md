IT担当がいないと、Windowsの設定が今どうなっているのかを誰も見ていない、ということが起きます。専門の人を呼ぶ前に、設定画面を数か所たどるだけで確認できることがあります。

この記事では、ネットワークの種類、ファイアウォール、リモートデスクトップ、Windows UpdateとMicrosoft Defenderの状態を順に確認します。コマンドが苦手でも、設定画面の操作だけで進められるように書きました。PowerShellの確認コマンドは、各節の最後に1つだけ補足として載せています。

画面の名前は、Windows 11の日本語表示を前提にしています。Windowsのバージョンや更新状況によって、名前や並びが少し違う場合があります。会社のPCで、管理者が設定を固定していることもあります。その場合は変更せず、管理している人に伝えてください。

## なぜ今、設定を確認するのですか？

**結論：設定は一度決めたら見直さないことが多く、気づかないうちにオフになっていたり、古いままだったりするためです。**

総務省の「国民のためのサイバーセキュリティサイト」は、基本の対策の最初に「ソフトウェアを最新に保とう」を挙げています。サポートが切れたソフトウェアを使い続けないことも、同じサイトで勧められています。

Windows 10については、Microsoftが2025年10月14日で無償の更新プログラムと技術サポートを終了したと案内しています。Windows 10のPCが残っている場合は、Windows 11へ移る計画も合わせて考えてください。

## ネットワークが「パブリック」か「プライベート」か、どう確認しますか？

**結論：設定の「ネットワークとインターネット」で、つないでいるネットワークの「ネットワーク プロファイルの種類」を見ます。迷ったらパブリックにしておきます。**

Windowsは、ネットワークごとに「パブリック」と「プライベート」を使い分けます。Microsoftの説明では、次のとおりです。

- パブリック：PCは他の機器から見えなくなります。ファイルとプリンターの共有は使えません。
- プライベート：PCは他の機器から見えるようになります。ファイルとプリンターの共有が使えます。知っている人と機器だけがいる環境で使う設定です。

Windows 11では、はじめてつないだネットワークはパブリックになるとMicrosoftが案内しています。それを自分でプライベートに変えた覚えがあるなら、変えた先が本当に自分たちだけのネットワークか、一度見てください。

確認の手順は次のとおりです。

1. 「スタート」から「設定」を開き、「ネットワークとインターネット」を選ぶ
2. つないでいる接続（「Wi-Fi」または「イーサネット」）を選ぶ
3. 接続中のネットワークの画面で、「ネットワーク プロファイルの種類」を見る
4. 共有が必要なオフィスの社内ネットワーク以外は、「パブリック ネットワーク」を選ぶ

補足のコマンドです。PowerShellで次を実行すると、種類が `Public` か `Private` で表示されます。

```text
Get-NetConnectionProfile
```

## ファイアウォールは、すべてのプロファイルで有効になっていますか？

**結論：Windows セキュリティの「ファイアウォールとネットワーク保護」で、ドメイン・プライベート・パブリックの3つとも「オン」になっているか確認します。**

Microsoftは、ネットワークを職場（ドメイン）、信頼できる（プライベート）、信頼できない（パブリック）の3種類に分けて、それぞれにファイアウォールの設定があると説明しています。いま使っているネットワークの種類は、この画面に表示されます。

手順です。

1. スタートメニューで「Windows セキュリティ」を検索して開く
2. 「ファイアウォールとネットワーク保護」を選ぶ
3. 「ドメイン ネットワーク」「プライベート ネットワーク」「パブリック ネットワーク」を1つずつ開く
4. 「Microsoft Defender ファイアウォール」が「オン」になっているか見る
5. オフなら、スイッチを「オン」に切り替える

Microsoftは、ファイアウォールをオフにすると、不正なアクセスを受けやすくなる可能性があると案内しています。ブロックされるアプリがあって困る場合も、ファイアウォール全体を切るのではなく、そのアプリを許可する方法が勧められています。

3つのうち、いま使っていないプロファイルがオフのまま残っていることがあります。出張先でパブリックにつなぐときに困るので、使っていない分も見ておいてください。

補足のコマンドです。次を実行すると、3つのプロファイルの `Enabled` が `True` か分かります。

```text
Get-NetFirewallProfile | Select-Object Name, Enabled
```

## リモートデスクトップを使っていないなら、オフにできますか？

**結論：使っていないならオフにします。使う場合は、接続できるユーザーを絞り、ネットワーク レベル認証（NLA）を有効にします。**

リモートデスクトップは、別の場所のPCを自分のPCのように操作する機能です。Microsoftの説明では、有効にするとPC上でポートが開き、同じネットワーク内の機器から接続できる状態になります。手元で使うだけなら有効にする必要はない、とも書かれています。

手順です。

1. 「設定」を開き、「システム」を選ぶ
2. 「リモート デスクトップ」を開く
3. 使っていなければ、スイッチが「オフ」か確認する。オンなら、オフに切り替える

なお、Windows 11 Homeは、リモートデスクトップで「つながれる側」にはなれません。Microsoftは、接続される側にできるのはPro、Enterprise、Educationなどのエディションだと案内しています。Homeのパソコンでこの項目が見当たらなくても、おかしくはありません。

使っている場合は、次の3点を見直してください。

- 接続を許可するユーザーが、本当に必要な人だけか。Microsoftによると、リモートデスクトップが有効なとき、Administratorsグループの全員と、指定したユーザーが接続できます。「リモート デスクトップ ユーザー」の画面で、見覚えのないアカウントがないか見てください。
- 接続するアカウントのパスワードが、他のサービスと使い回されていないか。Microsoftは、リモート接続を許可するアカウントには、強力で固有のパスワードを設定するよう案内しています。
- NLAが有効か。NLAは、接続が始まる前に認証を済ませる仕組みです。Microsoftは、多くの環境で有効にすることを勧めています。古い機器から接続できないときは一時的に無効にする場合もありますが、できるだけ有効のままにしておくよう案内しています。「設定」>「システム」>「リモート デスクトップ」で、リモート デスクトップのスイッチの右にある「∨」を開くと、「接続にネットワーク レベル認証を使用することをデバイスに要求する」というチェック項目があります。ここにチェックが入っているか見ます。

インターネットの外側から自宅や事務所のPCに入る必要があるときは、ルーターでポートを開けるより、VPNを使う方法があります。Microsoftも、社外から接続するならポート転送かVPNと案内しています。設定には専門知識が要るので、ここは詳しい人に頼んでよい部分です。

接続元のIPアドレスを絞る設定は、「セキュリティが強化されたWindows Defender ファイアウォール」の受信規則にあります。ただ、画面が分かりにくく、間違えると自分も接続できなくなります。自信がなければ、無理に触らないでください。

補足のコマンドです。次を実行して `0` ならオン、`1` ならオフです。

```text
(Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server').fDenyTSConnections
```

## Windows UpdateとMicrosoft Defenderは、最新の状態ですか？

**結論：Windows Updateで「最新の状態です」と出ること、Windows セキュリティで「ウイルスと脅威の防止」に警告が出ていないことを見ます。**

Windows Updateの確認手順です。

1. 「設定」を開き、「Windows Update」を選ぶ
2. 更新プログラムが残っていないか見る。残っていれば「更新プログラムのチェック」から進める

Windows 11は更新プログラムを自動でダウンロードしてインストールします。Microsoftによると、再起動は使っていない時間に行うよう試みられますが、できなければ再起動の予約を求められます。再起動を先送りしている間は、更新が適用されないままです。

次に、ウイルス対策の状態です。

1. 「Windows セキュリティ」を開く
2. 「ウイルスと脅威の防止」を選ぶ
3. 警告やエラーの表示がないか見る
4. 「ウイルスと脅威の防止の設定」の下にある「設定の管理」を開き、「リアルタイム保護」が「オン」か見る

Microsoftは、リアルタイム保護がオフの間は、開いたりダウンロードしたりしたファイルがスキャンされないと説明しています。しばらくすると自動でオンに戻るとも書かれています。他社のセキュリティソフトを入れている場合は、画面の表示が変わります。その場合は、そのソフトの管理画面で期限切れになっていないかも見てください。

総務省のサイトも、セキュリティ対策ソフトを活用するよう勧めています。

補足のコマンドです。次を実行すると、リアルタイム保護の状態と、ウイルス定義の最終更新日時が分かります。

```text
Get-MpComputerStatus | Select-Object RealTimeProtectionEnabled, AntivirusSignatureLastUpdated
```

## 公共Wi-Fiでは何に気をつけますか？

**結論：つなぐ前に暗号化されたネットワークを選び、つないだら種類が「パブリック」になっているか見ます。共有は使いません。**

カフェや駅、ホテルのWi-Fiで仕事のPCを使うときは、次の点を見ます。

- 暗号化されたネットワークを選ぶ。Microsoftは、暗号化されていない「オープン」なネットワークを避け、暗号化されたものを選ぶよう案内しています。パスワードなしでつながるWi-Fiは、通信の内容が他人に見られるおそれがあります。
- 「自動的に接続」と「このネットワークを記憶する」を付けない。Microsoftは、自分で管理していないWi-Fiには自動接続させないよう案内しています。過去に登録した無線ネットワークは、一覧から消せます。
- 接続後に、ネットワークの種類が「パブリック」か確認する。前の節のとおり、パブリックならPCは他の機器から見えず、ファイルとプリンターの共有も使えません。
- 使わない間はWi-Fiをオフにする。これもMicrosoftが挙げている方法です。

Microsoftは、VPNは暗号化されたネットワークでも安全性を足せると案内しています。社外で仕事をする機会が多いなら、会社で使っているVPNがあるか確認してください。

総務省のサイトには、無線LAN（Wi-Fi）の安全な利用についてのページや、古いWi-Fi機器を使い続けないことを呼びかける項目もあります。事務所のWi-Fiルーターが何年も前のままなら、あわせて見直す候補になります。

補足のコマンドです。PCがネットワークに共有しているフォルダーの一覧が出ます。`ADMIN$`・`C$`・`IPC$` はWindowsが最初から持っている管理用の共有です。それ以外に見覚えのない共有名がないかを見ます。

```text
Get-SmbShare
```

## 5分でできるチェックリストはありますか？

**結論：次の表を上から順に、設定画面で見ていきます。**

| 確認すること | どこを見るか | 目安 |
|---|---|---|
| ネットワークの種類 | 設定 > ネットワークとインターネット > 接続中のネットワーク | 外出先は「パブリック」 |
| ファイアウォール | Windows セキュリティ > ファイアウォールとネットワーク保護 | 3つのプロファイルとも「オン」 |
| リモートデスクトップ | 設定 > システム > リモート デスクトップ | 使わないなら「オフ」。使うならユーザーを絞り、NLAを有効に |
| Windows Update | 設定 > Windows Update | 更新プログラムが残っていない |
| ウイルスと脅威の防止 | Windows セキュリティ > ウイルスと脅威の防止 | 警告がなく、リアルタイム保護がオン |
| 公共Wi-Fi | Wi-Fiの一覧 | 自動接続と記憶を付けない。使わない登録は消す |
| Windowsのバージョン | 設定 > システム > バージョン情報 | サポートが続いているバージョンか |

この表は、基本の設定を見るための目安です。ここで何も問題が出なくても、すべての危険がなくなるわけではありません。パスワードの管理や、メールの添付ファイルへの注意、データのバックアップは別に必要です。

国家サイバー統括室（NCO）が公開している「インターネットの安全・安心ハンドブック」には、スマホやパソコン、IoT機器を安全に使うための設定を扱う章があります。一般の利用者や中小企業を対象にした資料なので、次に読む1冊として使えます。

生成AIに仕事の文章を入力する前の確認は、[生成AIを安全に使うための入力前チェック](/ai-jitan-lab/anzen-gyomu-bunsho/seisei-ai-anzen-nyuryoku-mae-check/)にまとめています。

## まとめ：設定画面を5か所見て、ずれていれば直す

ネットワークの種類、ファイアウォール、リモートデスクトップ、Windows Update、Windows セキュリティの5か所を見るだけで、よくある見落としは拾えます。直し方が分からない項目や、会社のポリシーで変更できない項目は、無理に触らず、管理者や詳しい人に伝えてください。
